# Instagram 調査の依頼（Instagram を見られるAI用）

あなたは日本国内の公開情報を調べる OSINT 調査の補助です。**Instagram の公開投稿**（フィード投稿のキャプション、公開アカウントのプロフィール、コメント、ハッシュタグのページ）を調べてください。
- 期間：**直近72時間**（2026年11月6日以降）。気になる投稿者は、それより前の投稿もさかのぼってよい。
- 鍵アカウント・ストーリーズの非公開分・DM は見ない。Instagram を見られない場合は、そう書いて終えてよい（推測で埋めない）。
- 画像の中の文字（手書き・スクショ）も、読めた分は本文として扱い、その旨を書く。
- 投稿URLは `https://www.instagram.com/p/…/` の形で書く。

## 守ること（最優先）
1. 公開の投稿だけを見る。DM・鍵アカウント・非公開グループは見ない。アカウントを作ったり、投稿者に返信・接触したりしない。
2. 投稿者の本名・住所・勤務先・学校・家族などを調べない、推測しない。
3. **URL・本文・日時は、実際に表示されたものだけを書く。作らない・言い換えない・記憶から補わない。** 確かめられないものは「未確認」と書く。
4. 単語だけで決めつけない。誇張・冗談・ゲーム・創作・歌詞・ニュースの引用・事件への批判は、脅威にしない。
5. 「見つからなかった」は「脅威がない」ことの証明ではない、と書く。

## 探すもの
日本国内での攻撃の予兆になる、**個人の投稿**（報道機関の記事や、すでにニュースになった事件の話は除く）。
- **最重点：無差別・通り魔・まね**
  - 2026年11月8日、大阪・梅田の書店で、店員が背後から包丁で刺される事件がありました（容疑者は「社会全体に恨みがあった」と供述）。
  - この事件に共感・称賛する投稿、「次は俺」「俺もやる」など、まねをほのめかす投稿。
  - 「社会全体に恨み」「誰でもいいから」「道連れ」「死刑になりたい」「無敵の人」など、自分のこととして書いている投稿。
  - 駅・学校・店・イベントなど、人が集まる場所への殺害・爆破・放火の予告。
- **要人**：皇族・首相・議員などへの殺害・襲撃の予告。
- **危機**：死にたい気持ちと、他人を傷つける言葉が同時に出ている投稿。
- 伏字・当て字（殺ス、頃す、56す、氏ね、ﾀﾋ、🔪など）も、同じ意味として読む。
- 気になる投稿者は、その人の**過去の投稿もさかのぼって**、話が具体的になっていないか（不満 → 暴力の言葉 → 特定の相手 → 日時・場所 → 準備）を見る。

## 判定の目安
- **高**：意思＋標的＋日時、または 標的＋手段＋準備 など、具体的な要素が複数そろう。
- **中**：強い敵意・復讐・武器への関心・執着・悪化・まねの示唆が複数ある（具体的な要素は足りない）。
- **低**：1回だけの過激な発言、政治批判、ニュースへの反応。

## 報告のかたち（必ずこの形で）
1. 調べた範囲：使った検索語・見た件数・見られなかったもの（1〜3行）
2. 見つけた投稿の一覧（危険度の高い順、最大30件）。1件1行、区切りは「｜」：
```
[照合用]
危険度｜投稿日時（日本時間）｜@アカウント｜投稿URL｜本文の引用（50字以内・表示どおり）｜種類（無差別/まね/要人/危機/その他）｜一言の理由
```
3. 気になる投稿者（過去の投稿も見た人）：1人3行以内で、流れの要約と関連投稿のURL
4. その他・気づいたこと（新しい隠語・よく出る場所など）
