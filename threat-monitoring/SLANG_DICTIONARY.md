# 伏字・隠語・表記変形 辞書 ＆ 24時間検索クエリ集

用途: 24時間以内・未報道の個人投稿から、テロ／大量殺傷につながるおそれのある Threat Indicator を検出する。
検索実行: ユーザー側（X ログイン環境 or Yahoo!リアルタイム検索）。評価: Claude（貼り付けられた投稿テキスト・URL・スクショを分析）。

> 注意: 本辞書の語の多くは日常・ゲーム・ネットスラングで無害に使われる。**ヒット＝脅威ではない**。必ず「Target / Time / Location / Method / Preparation」の組合せで評価する（INSTRUCTIONS_Claude.md §7）。

## 2. 意味カテゴリ別 隠語・婉曲表現

### Intent（加害意思）
- 殺傷: ◯す 4ね タヒね 消す 処す 始末する 片付ける やる（文脈依存） 刺す ブスッと 刻む 道連れ 巻き添え
- 大量: 何人やれるか 一人でも多く 無差別 まとめて 全員 スコア 記録更新 ハイスコア（※模倣犯界隈の「犠牲者数＝スコア」）
- 爆破・放火: 吹き飛ばす 花火（文脈依存） 燃やす 灯油 ガソリン 着火 火祭り
- 車両: 突っ込む 轢く アクセル踏む 歩行者天国に突っ込む

### Crisis / 最終性（危機表現 ＝ 最重要の組合せ指標）
- 最後の仕事 最後に一花 全部終わらせる 人生終了 失うものはない 無敵の人 どうせ死ぬなら 死刑になりたい 誰でもよかった（事後に多い語を事前に使う例） 明日で終わり 遺書 これが最後の投稿

### Grievance（恨み）
- 落とし前 報いを受けさせる 思い知らせる 復讐 社会に復讐 世間に分からせる 一矢報いる 見返す（文脈依存）

### Copycat（模倣・称賛）
- 過去事件の犯人名・事件名＋「神」「英雄」「尊敬」「続く」「次は俺」「俺もやる」「記録を超える」
- 海外: "saint" "highscore" "go ER"（エリオット・ロジャー由来、加害称賛文脈）、"beta uprising"、"ACAB"は単独無害
- 国内事件名の略称・ネタ化表現（新たに発見したら追記）

### Approach / Time / Location（接近・日時・場所）
- 会いに行く 直接行く 待つ 待ち伏せ 出待ち 入り待ち 現地 会場 乗り込む 凸（とつ）する 突撃 本人に会う 当日楽しみ そこで会おう
- 日時語: 明日 今夜 週末 当日 X日 ◯時に 決行 Xデー
- 場所: 駅名 学校名 施設名 演説 街頭演説 イベント フェス ライブ 握手会

## 3. 運用

- 具体的な Target・日時・場所を伴う投稿を見つけた場合は、評価を待たずに警察（110）へ通報する。
## 4. 検索エンジン別の注意（運用で判明）
- Yahoo!リアルタイム検索: スペースはAND、記号（◯○〇●）は無視される。分割表記・伏字は検索語にせず、取得結果を正規表現で検査する。
- 新出: 「56して」（殺して）。
- 定型の誇張（原則「低」）: 「〜したら殺す」「殺す気か」「全員4ね」「職場/学校を爆破したい」（休み願望）。ただし Target が実在の特定施設・人物で、日時・手段が加わったら再評価。

## 5. 参考事例（ユーザーが「当たり」と判断したアカウントの型）
個人の特定ではなく、似た投稿者を見つけるための型として残す。

### 参考事例A：皇室中傷型（2026-11-02 確認）
- 内容: 秋篠宮さまの出生を否定する陰謀論（「安西孝之の子」「DNA」「皇族ではない」）を断定的に繰り返す。「皇室から出て行け」「税金を使うのは止めろ」。「秋篠宮さまの黙秘はいつまで？」系の記事を引用して罵倒を付ける。地方自治体への来訪に触れる。
- 書き方: 半角の｢｣や､を使う。「〜だぞぉ〜」「〜だべぇ」などの口語。ニュース記事に改行の多い評論を付ける。無害な連投（音楽の紹介など）の合間に、皇室への中傷を挟む。
- 周りの反応: 他の利用者から「通報しました」の返信が付く。
- 見つけ方: 「安西孝之」「秋篠宮 DNA」「皇室から出て行け」「皇族ではない」「黙秘はいつまで」で単語検索し、引用記事を共有している他のアカウントもたどる。
- 判定: この型そのものは中傷で、脅威ではない。暴力の言葉、行事・会場（育樹祭・白浜・田辺など）への来訪、日時、「行く」「待つ」などの接近の言葉が加わったら、危険度を上げる。

### 6-3. 運用
- 6-2 の蔑称は、検索語と重点の印（FOCUS）に入れた。蔑称で書く人は、正式名を避けて検索から逃れていることが多い。
- 6-1 の闇バイト語は、文脈を読むための参考にとどめる。**闇バイトの募集投稿そのものは調査対象外**（検索語にも入れない）。強盗・襲撃などの加害の意思を本人が書いている場合だけ、通常の基準で評価する。
- 自殺の手段に関する隠語は、一覧化しない（拡散の危険があるため）。危機の言葉が出たら、相談窓口（いのちの電話 0570-783-556 など）の案内を添える。
