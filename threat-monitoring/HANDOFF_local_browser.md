# 方法2：ユーザーのパソコンで Instagram / Facebook / Threads / X を調査する手順

クラウド版のClaudeは、ログインが必要なSNSを見られない。ユーザーのパソコン上のClaudeに、ログイン済みのChromeを操作させて補う。

## 1. 準備（約10分）
1. Claude Desktop アプリを入れる（またはターミナルで `claude remote-control` を実行して、このリポジトリのフォルダで起動する）
2. Chrome に拡張機能 **Claude in Chrome** を入れて、Claude Desktop と接続する
3. 調査専用のChromeプロファイルを作り、次にログインしておく（個人用アカウントと分けること）
   - X、Instagram、Facebook
   - 調査用の別アカウントを使うこと。本アカウントは使わない（アカウント停止・個人情報の露出を避けるため）
4. このリポジトリを取得する: `git clone https://github.com/st16181995-a11y/my-project` → ブランチ `claude/vehicle-system-rebuild-8gmm4j`

## 2. 守ること
- 閲覧するだけ。フォロー、いいね、コメント、DM、スクリーンショット共有、本人への接触は一切しない
- 投稿の自動大量取得（スクレイピング）はしない。各SNSの規約で禁止されており、アカウント停止につながる。1回あたり確認する件数を絞る（目安：検索語ごとに上位20件程度、全体で100件以内）
- 非公開アカウント、DM、非公開グループには入らない。承認を求められる画面で止まる
- 具体的な標的・日時・場所・手段を伴う投稿を見つけたら、評価を待たずに警察（110）またはサイバー通報窓口へ。本人に接触しない
- 個人の特定（本名、住所、勤務先など）はしない。公開された投稿の内容だけを記録する

## 3. 貼り付ける依頼文（パソコン側のClaudeへ）

```
threat-monitoring/INSTRUCTIONS_Claude.md と threat-monitoring/SLANG_DICTIONARY.md を読んでください。
Chromeにログイン済みの調査用アカウントで、X・Instagram・Facebook・Threads の公開検索を使い、
直近24時間以内の個人の投稿だけを調べてください。ニュース等で既に報じられた事案は除外します。

検索:
- SLANG_DICTIONARY.md の語（伏字・数字・ローマ字・絵文字を含む）と、Target語（学校・駅・演説・イベント等）の組み合わせ
- 各SNSの「最新」タブ、ハッシュタグ検索、地域・場所タグを使う
- 検索語ごとに上位20件程度まで。全体で100件以内。1回ごとに短い間隔を置く

守ること:
- 閲覧のみ。フォロー・いいね・コメント・DM・投稿はしない
- 非公開・要承認のアカウントは開かない
- 個人情報の推測や特定はしない

出力:
- INSTRUCTIONS_Claude.md の §8 の形式で、危険度・情報確度を分けて報告
- 具体的な Target / Time / Location / Method / Preparation があれば【緊急確認推奨】とし、警察への通報を促す
- 結果は threat-monitoring/logs/YYYY-MM-DD_local.md に保存し、コミット・プッシュ
- 見つからなかった場合は「今回の公開検索では確認できなかった」と書く（脅威がないとは書かない）
```

## 4. 限界
- DM、非公開アカウント、ストーリーズ、24時間で消える投稿の一部は見られない
- 各SNSの検索は、ログインしていても件数や並びが制限される
- 検索語によっては、安全上の判定でClaudeが実行を断る場合がある（その場合は結果を貼り付けてもらい、評価だけ行う）
- ログイン済みの調査用アカウントが制限・停止される可能性がある
